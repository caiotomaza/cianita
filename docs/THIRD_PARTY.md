# Código e dependências de terceiros

A base Laravel da Cianita foi preparada a partir do esqueleto oficial [laravel/laravel](https://github.com/laravel/laravel) (branch 13.x, consultada em 2026-11-15), disponível sob licença MIT, e depois modificada e ampliada para este projeto.

As bibliotecas PHP e JavaScript utilizadas são distribuídas conforme as respectivas licenças dos pacotes. Consulte os arquivos de licença incluídos nas dependências instaladas e seus repositórios originais.

Esta atribuição não substitui a licença AGPL-3.0 já existente na raiz da Cianita. Nenhuma marca ou identidade visual do projeto Obsidian é incorporada.
